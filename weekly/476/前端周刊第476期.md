## 🗂 本期精选目录

### 🧭 Web Dev

* [如何阅读 GTmetrix 报告并优化 WordPress 速度](https://wp-rocket.me/blog/gtmetrix/)：介绍如何通过 GTmetrix 分析 WordPress 性能问题并进行优化，适合关注网站速度的开发者。
* [你的表单真的需要下拉列表吗？](https://www.nngroup.com/articles/dropdown-list/)：探讨表单设计中下拉列表的适用场景及替代方案，帮助提升用户体验。
* [在 Webflow 中构建实时 3D 体验](https://tympanus.net/codrops/2026/07/22/building-ridgeline-engineering-a-real-time-3d-experience-in-webflow/)：展示如何在 Webflow 中实现实时 3D 交互，适合对创意开发感兴趣的开发者。
* [从基础原则理解微前端](https://medium.com/@andrew.redican.mejia/microfrontends-from-first-principles-178aafe02ce5)：阐述微前端的核心概念及应用场景，适合希望深入了解该架构的开发者。

### 🎨 CSS

* [动画时间线：scroll() 替代滚动 JavaScript](https://agustinbarrientos.com/writing/senior-eye/animation-timeline-scroll/)：介绍 CSS 新特性 animation-timeline: scroll()，简化滚动动画的实现。
* [使用 text-fit 实现响应式 ASCII 艺术](https://css-tip.com/ascii-art/)：展示如何用 CSS 创建响应式 ASCII 艺术，适合对创意设计感兴趣的开发者。
* [像印刷页面一样设置排版](https://www.carmenansio.com/articles/editorial-typography-css/)：探讨如何用 CSS 实现印刷风格的排版设计，提升网页视觉效果。
* [CSS Infinity 的使用场景](https://nerdy.dev/css-infinity-use-cases)：介绍 CSS Infinity 的应用场景，扩展开发者的设计思路。
* [需要绘制三角形时，试试圆锥渐变](https://master.dev/blog/when-you-need-to-make-a-triangle-think-conic-gradients/)：展示如何用 CSS 圆锥渐变创建三角形，简化图形设计。
* [我的关注：highlight API、text-indent 和 font-family: math](https://utilitybend.com/blog/under-my-radar-highlight-text-indent-and-font-family-math)：分享 CSS 的几个实用功能，帮助开发者优化文本样式。
* [使用 CSS 的 animation-composition 避免重复声明](https://master.dev/blog/using-animation-composition-in-css-to-avoid-redeclaring-other-values/)：介绍如何通过 animation-composition 优化动画代码的可维护性。
* [基于时间的背景颜色过渡：Temporal 和 CSS color-mix](https://localghost.dev/blog/time-based-background-colour-transitions-with-temporal-and-css-color-mix/)：展示如何结合 Temporal 和 CSS color-mix 实现动态背景颜色过渡。

### 💡 JavaScripts

* [Fetch 不够用](https://www.jasnell.me/posts/fetch-is-not-enough)：探讨 Fetch API 的局限性及替代方案，适合关注数据请求的开发者。
* [管理的绝对状态](https://infrequently.org/2026/07/state-management/)：分析 JavaScript 状态管理的现状及发展方向，适合框架开发者参考。
* [多数 JavaScript 开发者在面试中误解 == 的原因](https://medium.com/@dheeraj.bartwal91/most-javascript-developers-get-wrong-in-interviews-not-because-its-hard-729901790e2d)：探讨 JavaScript 中 == 的常见误区，帮助开发者备战面试。
* [Angular 22 正式采用 Signal-First：更新内容一览](https://javascript.plainenglish.io/angular-22-is-officially-signal-first-heres-everything-that-changed-here-s-what-changes-in-ng-b026fd81a3a4)：总结 Angular 22 的最新特性及变化，适合框架用户了解更新细节。
* [React Hook Form 避免状态，TanStack Form 作用域化状态](https://www.adarsha.dev/blog/react-hook-form-and-tanstack-form-state-models)：比较两种表单管理库的状态模型，帮助开发者选择合适工具。
* [Props、Composers 和 Providers：我们正在趋向的组合模式](https://backstage.orus.eu/react-composition-patterns-at-orus/)：探讨 React 中的组合模式，帮助开发者优化组件设计。
* [React Flight 协议的攻击与防御：反序列化漏洞](https://www.smashingmagazine.com/2026/07/weaponizing-defending-react-flight-protocol/)：分析 React Flight 协议的安全问题及防御策略，适合关注安全的开发者。
* [介绍 microcharts：React 的文字大小图表](https://meetguns.com/blog/microcharts-word-sized-charts)：展示如何用 microcharts 创建小型图表，适合数据可视化场景。
* [如何在生产环境中发现 Next.js 的内存泄漏](https://xabierlameiro.com/blog/nextjs/nextjs-memory-leak-in-production)：分享排查 Next.js 内存泄漏的方法，适合优化性能的开发者。
