## 🗂 本期精选目录

### 🧭 Web Dev

* [逆向工程 ChatGPT：OpenAI 如何支持十亿用户](https://performance.dev/chatgpt)：文章探讨了 ChatGPT 的 Web 实现及其支持大规模用户的技术基础，对高并发系统的开发者很有启发。
* [TypeScript 7.0 发布](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)：TypeScript 7.0 带来了新特性和改进，是前端开发者不可错过的更新。
* [前端领域的变化：你错过了什么](https://davidpoblador.com/deep-dives/what-happened-to-the-frontend/)：总结了前端技术的最新趋势和变化，适合了解行业动态的开发者阅读。
* [代理化 Web 的未来](https://bandarra.me/posts/the-agentic-web)：探讨了 Web 的代理化趋势及其潜在影响，为未来技术发展提供了新视角。
* [如何利用 GTmetrix MCP 和 AI 优化电商性能](https://gtmetrix.com/blog/how-growth-by-sabir-uses-gtmetrix-mcp-and-ai-to-optimize-performance-across-200-ecommerce-brands/)：分享了 GTmetrix 和 AI 在电商性能优化中的实际应用案例，值得性能优化从业者参考。
* [虚空开发：2026 年 6 月回顾](https://voidzero.dev/posts/whats-new-jun-2026)：总结了 6 月的技术动态和开发者社区的热点内容，适合快速了解趋势。
* [Vite+ Beta 发布](https://voidzero.dev/posts/announcing-vite-plus-beta)：Vite+ 的 Beta 版本发布，带来了新功能和改进，适合关注构建工具的开发者。
* [Edge 开发者更新：布局间隙、键盘无障碍和 PWA 迁移](https://blogs.windows.com/msedgedev/2026/07/07/new-in-edge-for-developers-style-layout-gaps-improve-keyboard-accessibility-and-migrate-your-pwa-to-a-new-origin/)：介绍了 Microsoft Edge 的新功能更新，帮助开发者提升用户体验。
* [用轻量化技术创建沉浸式 WebGL 体验](https://tympanus.net/codrops/2026/07/10/the-sleepers-creating-an-atmospheric-webgl-experience-with-lightweight-techniques/)：展示了如何使用轻量化方法构建高效的 WebGL 体验，适合对图形开发感兴趣的读者。
* [用 Three.js 构建交互式波传播立方体网格](https://tympanus.net/codrops/2026/07/09/building-an-interactive-wave-propagation-cube-grid-with-three-js/)：通过 Three.js 构建动态波传播效果的教程，适合学习 3D 可视化的开发者。
* [使用 Blender 相机路径、Three.js 和 GSAP 构建滚动驱动的 3D 画廊](https://tympanus.net/codrops/2026/07/07/building-a-scroll-driven-3d-gallery-using-a-blender-camera-path-with-three-js-and-gsap/)：结合多种工具实现滚动驱动的 3D 效果，适合探索动画和 3D 开发的读者。

### 🎨 CSS

* [关于锚定界面设计](https://karlkoch.me/writing/on-anchored-interfaces)：分析了锚定界面的设计原则和应用场景，提供了实用的设计建议。
* [锚点定位入门](https://www.joshwcomeau.com/css/anchor-positioning/)：详细介绍了 CSS 中锚点定位的基础知识，适合初学者学习。
* [强大的 CSS border-shape 属性即将到来！](https://css-tricks.com/get-ready-for-the-powerful-css-border-shape-property/)：预览了即将推出的 CSS border-shape 属性及其潜在用例，值得关注。
* [CSS 中的边界感知样式](https://master.dev/blog/boundary-aware-styling-in-css/)：探讨了如何在 CSS 中实现边界感知样式，提升设计灵活性。
* [如何让交互元素不可见但可访问](https://master.dev/blog/how-to-make-an-interactive-element-invisible-but-accessible/)：提供了在隐藏交互元素的同时保持其可访问性的技巧，兼顾设计与可用性。
* [CSS @layer 的水平思考](https://master.dev/blog/thinking-horizontally-in-css-layer/)：介绍了 CSS @layer 的使用方式及其在样式管理中的优势。
* [2026 年的现代 CSS：你可以删除的 JavaScript](https://www.alexcloudstar.com/blog/modern-css-2026-features/)：总结了 2026 年 CSS 的新特性及其对减少 JavaScript 依赖的影响。
* [CSS 缓动：从入门到精通](https://www.carmenansio.com/articles/css-easing-explained)：深入解析了 CSS 缓动函数的原理及其在动画中的应用。

### 💡 JavaScripts

* [ECMAScript 2026 的新特性](https://pawelgrzybek.com/whats-new-in-ecmascript-2026/)：介绍了 ECMAScript 2026 的新功能，帮助开发者了解 JavaScript 的最新进展。
* [你在大型项目中放弃的 React 模式](https://www.reddit.com/r/reactjs/comments/1uqqy52/whats_one_react_pattern_you_stopped_using_after/)：讨论了在大型 React 项目中被淘汰的设计模式，为开发者提供实践经验。
* [React 编译器解析](https://neciudan.dev/react-compiler-explained)：介绍了 React 编译器的工作原理及其在开发中的作用。
* [Proxy 和 Reflect](https://piccalil.li/blog/proxy-and-reflect/)：讲解了 JavaScript 中 Proxy 和 Reflect 的基本用法及其应用场景。
* [Angular Signal Forms 入门](https://www.telerik.com/blogs/getting-started-angular-signal-forms)：提供了关于 Angular Signal Forms 的入门教程，适合框架开发者学习。
* [用 React 构建实时无人机地面控制站](https://medium.com/@bytescribe/building-a-real-time-drone-ground-control-station-in-react-46e76adf12a3)：展示了如何使用 React 构建一个实时控制系统，适合对物联网开发感兴趣的读者。
