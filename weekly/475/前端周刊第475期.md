## 🗂 本期精选目录

### 🧭 Web Dev

* [API 令牌生命周期：从生成到泄露](https://www.jstools.space/blog/api-token-lifecycle/)：了解 API 令牌的完整生命周期，帮助开发者更好地管理和保护 API 访问权限。
* [为 Polyfills 辩护](https://lea.verou.me/blog/2026/polyfills/)：探讨 Polyfills 的价值与作用，适合开发者思考如何平衡兼容性与性能。
* [aria-expanded 的使用场景](https://piccalil.li/blog/use-cases-for-aria-expanded/)：介绍 aria-expanded 属性的应用场景，帮助开发者提升网页的可访问性。
* [保护 HTML 内容防止复制](https://jsdev.space/howto/protect-from-copying/)：分享防止 HTML 内容被复制的技术方法，适合需要保护原创内容的开发者。
* [如何在 Go 中使用 HTMX](https://www.alexedwards.net/blog/how-i-use-htmx-with-go)：展示 HTMX 与 Go 的结合使用，适合后端开发者了解前端集成方案。
* [Trionn 的架构：整合 GSAP、Three.js、Lenis 和 Web Audio](https://tympanus.net/codrops/2026/07/15/the-architecture-behind-trionn-coordinating-gsap-three-js-lenis-and-web-audio/)：分析复杂动画和音频项目的架构设计，适合对多媒体开发感兴趣的开发者。
* [我们还需要构建工具吗？](https://olliewilliams.xyz/blog/no-build/)：探讨现代前端开发是否仍需构建工具，适合关注开发流程优化的读者。
* [Vite 7 生产迁移：从 esbuild 到 Rolldown 和 Oxc](https://www.sitepoint.com/vite-7-production-migration-rolldown-oxc-build-optimization/)：介绍 Vite 7 的构建优化迁移过程，适合关注工具升级的开发者。
* [使用 Codemod 自动化 ESLint 迁移](https://eslint.org/blog/2026/07/eslint-codemod-migrations/)：分享通过 Codemod 工具简化 ESLint 迁移的经验，适合团队协作场景。
* [何时“阻塞”主线程是合理的](https://www.smashingmagazine.com/2026/07/when-makes-sense-block-main-thread/)：探讨主线程阻塞的合理场景，帮助开发者优化性能与用户体验。
* [使用 Lighthouse 实现网站最佳实践](https://www.debugbear.com/blog/lighthouse-best-practices)：介绍如何通过 Lighthouse 工具优化网站性能，适合关注质量提升的开发者。

### 🎨 CSS

* [OKHST：用于真实界面的可预测颜色生成](https://tenphi.me/blog/okhst-predictable-color-generation/)：探索 OKHST 颜色模型的应用，适合对设计系统感兴趣的开发者。
* [CSS 容器查询与子网格：构建上下文感知组件布局](https://www.sitepoint.com/css-container-queries-subgrid-component-layouts-2026/)：介绍容器查询和子网格的使用，适合开发复杂响应式布局的场景。
* [使用 sibling-index() 实现进出动画](https://master.dev/blog/in-n-out-animation-using-sibling-index/)：分享基于 sibling-index() 的动画设计技巧，适合提升交互效果的开发者。
* [重写 Sticky Detector 的经验教训](https://master.dev/blog/lessons-learned-rewriting-a-sticky-detector/)：总结重写 Sticky Detector 的实践经验，适合优化滚动交互的开发者。
* [如何使用 CSS contrast-color() 实现自动对比](https://blog.logrocket.com/css-contrast-color-auto-contrast/)：介绍 contrast-color() 的应用场景，帮助开发者提升设计的可读性。
* [用 CSS 子网格重建 FIFA 排名布局](https://ishadeed.com/article/fifa-layout/)：展示如何利用 CSS 子网格实现复杂布局，适合对网格系统感兴趣的开发者。
