### 3. GitHub Copilot app 入门指南：多 Agent 会话工作区与 Canvas 预览

**分类**：AI Coding · **来源**：GitHub Blog

GitHub Copilot app 将 AI 编码工具升级为多 Agent 会话工作区，支持同时管理多个任务线程而不丢失进度。用户可为每个会话绑定项目上下文，通过 `/create-canvas` 命令在浏览器 Canvas 中预览 UI 并直接点选修改，还能启用 Agent Merge 自动处理 PR 审查反馈和合并冲突。

> 行业整合信号值得关注，可能影响生态格局

[阅读原文](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-getting-started)

### 4. Kimi K3 开放日：模型权重、技术报告和关键 Infra 技术同步开放

**分类**：AI Coding · **来源**：公众号：月之暗面（Kimi）

月之暗面发布 2.8 万亿参数的混合专家模型 Kimi K3，支持原生视觉理解和 100 万 token 上下文窗口。其规模化效率较 Kimi K2.5 提升 2.5 倍，并同步开源模型权重、技术报告及 MoonEP、FlashKDA、AgentEnv 三项 Infra 技术。

> 新能力发布直接影响开发者工具链，值得第一时间关注

[阅读原文](https://mp.weixin.qq.com/s/IW9BdyA3hLvuuiX_aMCJEQ)

### 5. 黄仁勋、Kimi K3，与一场即将到来的开源战争

**分类**：AI Coding · **来源**：公众号：数字生命卡兹克

7月27日，月之暗面正式开源全球首个3T级模型Kimi K3，含2.8万亿总参数、1040亿激活参数，并公开47页技术报告及MoonEP、FlashKDA等关键基础设施。此前美国白宫指控K3蒸馏Claude模型，黄仁勋联合英伟达、微软、OpenAI等77家组织反对封禁中国开源模型。
