## 🗂 本期精选目录

### 🧭 Web Dev

* [Astro 7.0 发布](https://astro.build/blog/astro-7/)：Astro 7.0 带来了新的功能和优化，是构建静态网站的又一重要更新。
* [SVG 的不足之处](https://patrickbrosset.com/articles/2026-06-22-whats-missing-from-svg/)：探讨 SVG 在现代 Web 开发中的局限性，并提出改进建议。
* [Cloudflare Workers 入门](https://master.dev/blog/introduction-to-cloudflare-workers-for-web-apps/)：了解如何使用 Cloudflare Workers 构建高性能的 Web 应用。
* [WebMCP：为 AI 代理优化网站](https://www.debugbear.com/blog/webmcp)：介绍如何优化网站以更好地支持 AI 代理的交互。
* [2026 核心网络指标：修复交互到下次绘制](https://www.sitepoint.com/core-web-vitals-2026-fix-interaction-to-next-paint/)：分析最新的核心网络指标更新及其优化方法。
* [Shopify 春季版背后的 Web 体验设计](https://tympanus.net/codrops/2026/06/26/engineering-the-web-experience-behind-shopifys-spring-26-edition-everywhere/)：揭秘 Shopify 最新版本的 Web 体验设计与工程实践。
* [Podium：将跑步变成故事的网站](https://tympanus.net/codrops/2026/06/23/podium-building-a-website-where-running-becomes-storytelling/)：探索如何通过设计和技术将跑步体验转化为叙事。
* [使用视图过渡为对话框添加动画](https://pqina.nl/blog/animating-the-dialog-element-using-view-transitions/)：学习如何使用视图过渡 API 为对话框元素实现流畅动画。

### 🎨 CSS

* [现代 CSS 主题：light-dark()、contrast-color() 和样式查询](https://una.im/modern-css-theming/)：介绍 CSS 中的新功能，帮助实现更灵活的主题切换和样式适配。
* [探索 Gap 装饰](https://master.dev/blog/lets-play-with-gap-decorations/)：展示如何使用 CSS gap 属性创建有趣的装饰效果。
* [CSS 中的 random() 实验](https://polypane.app/blog/experimenting-with-random-in-css/)：探讨 CSS 中 random() 函数的潜力及其应用场景。
* [通过锚点定位改进卡片模式](https://thatemil.com/blog/clickable-surface-expansion-using-anchor-position/)：研究如何利用锚点定位优化卡片组件的交互体验。
* [基于滚动驱动的反向滚动动画](https://css-tricks.com/scroll-driven-animations-opposing-scroll-directions/)：学习如何通过 CSS 实现基于滚动方向的动画效果。
* [网格布局中的 WCAG 2.4.3 问题](https://matuzo.at/blog/2026/grid-lanes-accessibility)：分析网格布局在无障碍性上的潜在问题及解决方案。
* [波浪形输入范围滑块](https://css-tip.com/wiggly-range-slider/)：展示如何使用 CSS 创建动态的波浪形滑块效果。
* [CSS 容器查询与子网格：布局三部曲](https://www.sitepoint.com/css-container-queries-subgrid-the-layout-trilogy-thats-now-in-every-browser/)：总结容器查询和子网格的功能及其在现代浏览器中的支持情况。

### 💡 JavaScripts

* [Node.js 五大 WebSocket 服务性能对比](https://evilmartians.com/chronicles/choose-your-fighter-benchmarking-5-websocket-servers-for-nodejs)：通过基准测试比较不同 WebSocket 服务的性能表现。
* [Babel 8 发布：仅支持 ESM，移除 ES5 默认支持](https://babeljs.io/blog/2026/06/16/8.0.0/)：Babel 8 的发布标志着对现代 JavaScript 的进一步支持和优化。
* [使用 TanStack Query 处理 Vue 中的变更](https://www.telerik.com/blogs/handling-mutations-tanstack-query-vue)：介绍如何在 Vue 项目中利用 TanStack Query 高效管理数据变更。
* [Bulletproof React：GitHub 上最受欢迎的 React 架构](https://jsdev.space/bulletproof-react-architecture-guide/)：探讨 Bulletproof React 架构为何成为开发者的热门选择。
* [Linear 从 styled-components 迁移到 StyleX](https://www.skovhus.dev/blog/moving-linear-from-styled-components-to-stylex)：分享 Linear 在样式管理上的技术迁移经验。
* [TanStack Table：一次重构节省 90% 内存](https://tanstack.com/blog/tanstack-table-v9-memory-performance)：展示 TanStack Table 的性能优化背后的技术细节。
* [React 编译器：消除手动性能优化工作](https://www.sitepoint.com/react-compiler-eliminating-manual-performance-work/)：介绍 React 编译器如何自动化性能优化任务。
* [Next.js 16：Turbopack、React 编译器与缓存](https://www.sitepoint.com/nextjs-16-turbopack-react-compiler-cache/)：概述 Next.js 16 的新特性及其对开发效率的提升。
* [深入解析 React：虚拟 DOM、协调与 Fiber](https://medium.com/@ddhote780/react-behind-the-scenes-virtual-dom-reconciliation-render-phase-commit-phase-fiber-explained-c7625609491a)：详细剖析 React 的核心机制及其工作原理。
* [为 React 编写自定义渲染器](https://www.callstack.com/blog/writing-custom-renderers-for-react)：了解如何为 React 创建自定义渲染器以满足特定需求。
* [React 19 的 useOptimistic 和 useActionState](https://www.sitepoint.com/react-19s-useoptimistic-and-useactionstate-replacing-80-of-your-state-boilerplate/)：探讨 React 19 新特性如何简化状态管理代码。
