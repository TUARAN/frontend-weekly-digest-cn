## 🗂 本期精选目录

### 🧭 Web Dev

* [关于语义网的探讨](https://karlkoch.me/writing/on-the-semantic-web)：语义网是未来网络的一部分，它旨在让数据更易于机器理解。了解其发展方向可以帮助开发者更好地设计数据结构。
* [Safari MCP服务器介绍](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/)：Safari MCP服务器为开发者提供了新的工具支持，优化了浏览器与服务器之间的通信流程，是提升开发效率的有力工具。
* [Dan Abramov加入Next.js团队](https://bsky.app/profile/danabra.mov/post/3mp5b3nd3ws2k)：React核心开发者Dan Abramov以兼职形式加入Next.js团队，这可能为框架带来新的技术突破和社区支持。
* [Lighthouse评估网站是否适配AI代理](https://techhub.iodigital.com/articles/is-your-site-ready-for-ai-agents-lighthouse-now-has-an-answer)：Lighthouse新增功能帮助开发者评估网站对AI代理的适配程度，为未来的AI应用场景做好准备。
* [Google I/O 2026：Web UI新动态](https://developer.chrome.com/blog/new-in-web-ui-io26?hl=en)：Google I/O 2026展示了Web UI领域的最新技术更新，包括性能优化和用户体验改进，值得关注。
* [HTML元素的引入](https://developer.chrome.com/blog/usermedia-html-element)：新的HTML元素简化了用户媒体权限管理，为开发者提供了更安全和直观的解决方案。
* [Chrome优化摄像头权限管理](https://blog.invidelabs.com/chrome-usermedia-html-element/)：Chrome通过新的HTML元素改进了摄像头权限管理，减少了应用层面的复杂性，提升了用户体验。
* [TypeScript成为GitHub最受欢迎语言](https://www.syncfusion.com/blogs/post/typescript-github-most-used-language)：TypeScript凭借其强类型和开发效率优势，成为GitHub上最受欢迎的语言，反映了其在前端开发中的重要性。
* [npm依赖的安全风险](https://blog.logrocket.com/npm-dependencies-bigger-security-risk-your-code/)：文章探讨了npm依赖可能带来的安全问题，提醒开发者在选择第三方库时需更加谨慎。
* [a11y.quest：提升无障碍技能的128个问题](https://a11y.quest/)：通过回答这些问题，开发者可以系统性地提升无障碍设计能力，改善用户体验。
* [无障碍设计是一种运营能力](https://www.smashingmagazine.com/2026/06/why-accessibility-operational-capability-not-feature/)：文章强调无障碍设计不仅是功能，更是一种运营能力，值得开发者从战略角度重视。
* [使用WebGPU和原生JavaScript构建持久页面过渡](https://tympanus.net/codrops/2026/06/30/building-persistent-page-transitions-with-webgpu-and-vanilla-javascript/)：WebGPU结合JavaScript实现流畅的页面过渡效果，为开发者提供了新的视觉设计可能。
* [Quake1移植：用HTML/CSS渲染3D几何](https://cssquake.com/)：通过PolyCSS技术，Quake1实现了无需WebGL或Canvas的3D渲染，为前端开发打开了新思路。
* [数字运动员的3D工作流探索](https://tympanus.net/codrops/2026/07/01/sculpting-a-digital-athlete-capturing-stefanos-tsitsipas-beyond-the-court/)：从摄影测量到动画优化，文章展示了完整的3D工作流，为数字角色开发提供了参考。
* [无需GPU的WebGL实现](https://microlink.io/blog/webgl-without-a-gpu)：探索如何在没有GPU支持的情况下实现WebGL渲染，为设备受限的场景提供解决方案。

### 🎨 CSS

* [纯CSS实现故障文本效果](https://code.geohack.top/post/building-a-glitch-text-effect-with-nothing-but-css)：利用CSS技术实现动态的故障文本效果，展示了CSS在视觉设计中的潜力。
* [background-clip功能升级](https://css-tip.com/background-clip/)：background-clip属性迎来新功能，进一步提升了背景裁剪的灵活性和表现力。
* [利用progress()实现流体排版](https://master.dev/blog/fluid-typography-with-progress/)：progress()函数为流体排版提供了新的实现方式，简化了响应式设计的复杂度。
* [告别传统CSS：现代特性推荐](https://jsdev.space/modern-css-features/)：文章列举了现代CSS特性，帮助开发者摆脱传统写法，提升代码效率和可维护性。
* [CSS状态与JavaScript事件的界限变迁](https://css-tricks.com/css-states-and-javascript-events/)：分析CSS状态与JavaScript事件的交互关系，为开发者提供更清晰的设计思路。
* [修复全屏CSS布局问题](https://dbushell.com/2026/07/03/fixing-full-bleed-css/)：文章探讨了全屏布局中的常见问题，并提供了实用的解决方案。
* [Goldilocks自定义选择框高度](https://jakearchibald.com/2026/goldilocks-select-height/)：Goldilocks方法提供了一种灵活的选择框高度调整方式，提升了表单设计的用户体验。

### 💡 JavaScripts
